## METADATA STANDARDS

### Title Tag Format
- **Length**: <=60 characters
- **Format**: `[Primary Keyword] | [Secondary] | Komal Kids`
- **Brand Position**: Always last
- **Example**: `Online Safety for Kids Ages 6-10 | Safe Browsing | Komal Kids`

### Meta Description Format
- **Length**: <=155 characters
- **Structure**: Emotional hook + benefit + differentiator
- **Include**: Primary keyword naturally + GEO reference where natural
- **Example**: `Psychology-informed digital safety for children ages 6-10. Three-tier content filtering and peer-avatar guidance. Trusted by families in the US, India, and UK.`

### Keywords Strategy
- **Primary**: 1-2 main keywords per page
- **Secondary**: 3-5 supporting keywords
- **Natural**: Never stuff, always semantic
- **Intent**: Match search intent (informational/navigational/commercial)
- **GEO**: Organic geographic references (India, US, UK, Singapore, UAE)

## CONTENT PRINCIPLES

### DO
- Write for humans first, search engines second
- Use natural language and semantic keywords
- Reference "Talk-to-Play" as the core interaction model
- Prioritize trust over marketing
- Include concrete examples and specific data points
- Organically reference geographic markets (India, US, UK, Singapore, UAE)
- Reference school types naturally (CBSE, IB, GCSE, US public/charter)
- Maintain persona-appropriate tone
- Link internally naturally

### DON'T
- Keyword stuff
- Use buzzword stacking ("revolutionary AI-powered platform")
- Make exaggerated clinical claims
- Write generic, one-size-fits-all copy
- Neglect internal linking
- Skip structured data
- Forget mobile optimization
- Force geographic or school-type references where unnatural
