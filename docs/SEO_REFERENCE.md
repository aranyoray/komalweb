## 🔍 METADATA STANDARDS

### Title Tag Format
- **Length**: ≤60 characters
- **Format**: `[Primary Keyword] | Komal Kids`
- **Brand Position**: Always last
- **Example**: `AI Companion for Kids | Safe Digital Buddy | Komal Kids`

### Meta Description Format
- **Length**: ≤155 characters
- **Structure**: Emotional hook + benefit + CTA
- **Include**: Primary keyword naturally
- **Example**: `Discover Komal Kids, the safe AI companion for children. Real-time behavioral AI adapts to your child's needs with privacy-first design.`

### Keywords Strategy
- **Primary**: 1-2 main keywords per page
- **Secondary**: 3-5 supporting keywords
- **Natural**: Never stuff, always semantic
- **Intent**: Match search intent (informational/navigational/commercial)

## 🎨 CONTENT PRINCIPLES

### DO
- Write for humans first, search engines second
- Use natural language and semantic keywords
- Prioritize trust over marketing
- Explain differentiation clearly
- Include concrete examples
- Maintain persona-appropriate tone
- Link internally naturally

### DON'T
- Keyword stuff
- Use buzzword stacking
- Make exaggerated claims
- Write generic, one-size-fits-all copy
- Neglect internal linking
- Skip structured data
- Forget mobile optimization
